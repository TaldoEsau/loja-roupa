# Data Model: Freestyle Landing Page

## Entities

### Product
Represents an item in the catalog.
- `id` (string/number): Unique identifier.
- `title` (string): Name of the product (e.g., "Oversized Hoodie Dust Neon").
- `category` (string): Collection or type.
- `price` (number/string): Price to display.
- `imageUrl` (string): Path to the product image.
