# Quickstart Validation

## Prerequisites
- Node.js (v18+)
- pnpm or npm

## Setup
1. Run `npm install` in the project root.

## Validation Scenarios

### 1. Development Server
Run `npm run dev`. The site should open at `http://localhost:5173`.
- Scroll down to verify the hero animation plays forward.
- Verify the header background becomes blurred.
- Verify the product grid renders responsively.
